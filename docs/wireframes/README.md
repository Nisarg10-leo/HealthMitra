# Figma wireframe handoff

`healthmitra-wireframes.svg` contains six low-fidelity product screens required by the assignment. It is deliberately built from editable SVG vectors rather than a flattened image.

## Import into Figma Free

1. Open a new Figma Design file in your free account.
2. Drag `healthmitra-wireframes.svg` onto the canvas, or use **File → Import**.
3. Keep the six labelled artboards together as the wireframe board.
4. Optional: select each artboard and use **Frame selection** to make six named Figma frames.
5. Take one screenshot showing all six screens and a second screenshot showing the Figma file title.

## Screen rationale

| Screen | Requirement demonstrated |
| --- | --- |
| Sign in / choose role | Authentication and patient/caregiver role entry |
| Patient: today's medicines | Large tap targets, dose confirmation, voice action |
| Patient: SOS confirmation | Always-accessible emergency action and caregiver/location context |
| Patient: symptom checker | Fixed minor symptom list and mandatory safety disclaimer |
| Caregiver dashboard | Adherence chart, streak, current status, schedule |
| Alerts and SOS follow-up | Missed-dose alerts, SOS map state, acknowledge/resolve actions |
